# システム概要（β版）

ここでは、ObserLeaf（β版）の目的、概要、主な機能および動作環境についてまとめています。


## 1. β版の概要

β版では、ESP32を使用して植物の生育環境に関するデータを取得し、Wi-Fi経由でRaspberry Pi 5に送信するシステムを構築した。

温度・湿度・土壌水分・照度に関するデータを取得し、Raspberry Pi 5上で動作するDjangoアプリケーションを通じて受信・保存する。また、SQLiteを使用して計測データを管理し、Webブラウザから計測結果やその推移を確認できるようにした。

α版 v1ではRaspberry Pi 5にセンサーを直接接続していたが、β版ではセンサーの計測処理をESP32に分離し、ネットワーク経由でデータを送信する構成に変更した。


## 2. 主な機能

| 機能 | 内容 |
| --- | --- |
| 温度計測 | DHT11またはDHT22を使用して温度を取得する |
| 湿度計測 | DHT11またはDHT22を使用して湿度を取得する |
| 土壌水分計測 | 土壌水分センサーから値を取得し、土壌水分率に変換する |
| 照度計測 | LM393を使用した照度センサーから値を取得する |
| データ送信 | ESP32からWi-Fi経由で計測データをRaspberry Pi 5に送信する |
| データ受信 | Djangoアプリケーションでセンサーデータを受信する |
| データ保存 | SQLiteを使用して計測データを保存する |
| 植物管理 | 植物の種類や栽培情報を管理する |
| デバイス管理 | 計測デバイスの情報や計測間隔を管理する |
| データ可視化 | Djangoを使用して計測データをWebブラウザ上に表示する |
| 時系列表示 | 計測データの推移をグラフで確認する |


# 3. システムの範囲

β版では、以下の範囲を実装対象とした。

- ESP32による環境データの取得
- センサーデータの送信・受信
- センサーデータの保存・管理
- 植物および計測デバイスの管理
- 保存データのWebブラウザ上での可視化
- 計測データの時系列表示


# 4. 動作環境

| 項目 | 内容 |
| --- | --- |
| エッジデバイス | ESP32 |
| サーバー | Raspberry Pi 5 |
| OS | Raspberry Pi OS |
| プログラミング言語 | Python、Arduino系C/C++ |
| Webアプリケーション | Django |
| データ保存 | SQLite |
| 通信方式 | Wi-Fi、HTTP |
| 温湿度センサー | DHT11またはDHT22 |
| 土壌水分センサー | Capacitive Soil Moisture Sensor v1.2 |
| 照度センサー | LM393を使用した照度センサー |
| クライアント | PC Webブラウザ |


# 5. β版の位置づけ

β版は、α版 v1で構築したセンサーデータの取得・保存・可視化の基本機能を発展させ、ESP32による計測とネットワーク経由のデータ送信、DjangoによるWebアプリケーション、SQLiteによるデータ管理を組み合わせた段階である。

また、植物や計測デバイスの情報を管理できる構成とし、複数の植物やデバイスへの対応を見据えた設計とした。

今後は、環境条件に応じたアラート通知機能の実装や、実際の植物を用いた計測・検証を進め、植物の生育環境の把握と管理を支援するシステムを目指す。
