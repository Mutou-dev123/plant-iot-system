# システム概要（α版 v1）

ここでは、ObserLeaf（α版 v1）の目的、概要、主な機能および動作環境についてまとめています。


## 1. α版 v1の概要

α版 v1では、Raspberry Pi 5にセンサーを接続し、植物の生育環境に関するデータを取得・保存・可視化する基本的なシステムを構築した。

温度・湿度・土壌水分を計測し、取得したデータをCSVファイルに保存する。また、Streamlitを利用してWebブラウザから計測結果を確認できるようにした。


## 2. 主な機能

| 機能 | 内容 |
| --- | --- |
| 温度計測 | DHT11を使用して温度を取得する |
| 湿度計測 | DHT11を使用して湿度を取得する |
| 土壌水分計測 | 土壌水分センサーから値を取得し、土壌水分率に変換する |
| データ保存 | 計測データをCSVファイルに保存する |
| データ可視化 | Streamlitを使用して計測データをWebブラウザ上に表示する |
| 時系列表示 | 計測データの推移をグラフで確認する |


## 3. システムの範囲

α版 v1では、以下の範囲を実装対象とした。

- センサーからの環境データ取得
- センサーデータの補正・変換
- 計測データのCSV保存
- 保存データのWebブラウザ上での可視化

一方、ユーザー管理、複数植物の管理、ネットワーク経由でのセンサーデータ送信などはα版 v1の対象外とした。


## 4. 動作環境

| 項目 | 内容 |
| --- | --- |
| エッジデバイス | Raspberry Pi 5 |
| OS | Raspberry Pi OS |
| プログラミング言語 | Python |
| Webアプリケーション | Streamlit |
| データ保存 | CSV |
| 温湿度センサー | DHT11 |
| 土壌水分センサー | Capacitive Soil Moisture Sensor v1.2 |
| AD変換器 | ADC0834-N |
| クライアント | PC Webブラウザ |


## 5. α版 v1の位置づけ

α版 v1は、センサーデータの取得から保存・可視化までの基本的な動作をするための試作段階である。

α版 v1で得られた結果や課題をもとに、後続のβ版ではシステム構成やデータ管理機能を発展させる。
