# ドキュメント構成

ここでは、ObserLeafのドキュメントの一覧と、読む順番についてまとめる。


## β版（現行）

現在のシステムのドキュメントである。番号の順に読むことで、全体像から詳細へ進める構成になっている。

| # | ドキュメント | 内容 |
| --- | --- | --- |
| 1 | [概要](beta/overview.md) | システムの目的、主な機能、動作環境 |
| 2 | [システム構成](beta/architecture.md) | 全体構成と、各コンポーネントの役割 |
| 3 | [ESP32仕様](beta/esp32-spec.md) | ESP32のピン配置、処理フロー、通信・時刻仕様 |
| 4 | [サーバー仕様](beta/server-spec.md) | Djangoアプリケーションの内部構成と処理仕様、起動・運用 |
| 5 | [データフロー](beta/data-flow.md) | データの流れと、APIごとのデータ項目 |
| 6 | [データ管理方針](beta/data-management.md) | データの保存・集計・削除の方針 |
| 7 | [ER図](beta/er-diagram.md) | データベースのテーブル構成 |
| 8 | [セットアップ・運用手順](beta/setup-guide.md) | 環境構築の手順と、日常的な運用操作 |

環境構築だけを行いたい場合は、まず概要（1）とセットアップ・運用手順（8）を読むことで足りる。
